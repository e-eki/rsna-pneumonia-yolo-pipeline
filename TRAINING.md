Обучение

Имя запуска задаётся через --run-name. Если не указано — генерируется автоматически с датой:

python -m src.train --config configs/config.yaml \
    --run-name "2026-10-02_full_yolov8s_30ep_no_mosaic"

Гиперпараметры
Все параметры — в configs/config.yaml, секция training.

Параметр	Значение	Почему так
model	yolov8s.pt	Компромисс скорость/качество. yolov8n — для smoke test, yolov8m — если есть время
epochs	30	Оптимум для Colab; метрики выходят на плато к 25-й эпохе
batch_size	16	Требует ~2.6 ГБ VRAM — влезает в T4 с запасом
imgsz	640	Стандарт YOLOv8, все предобученные веса под это разрешение
patience	10	Early stopping: если mAP не растёт 10 эпох — стоп
save_period	5	Промежуточные чекпоинты каждые 5 эпох (last.pt пишется каждую эпоху)
optimizer	AdamW	Стабильнее SGD на медицинских данных
lr0	0.001	Стандарт для AdamW
lrf	0.01	Финальный LR = lr0 * lrf = 1e-5
weight_decay	0.0005	Стандарт YOLOv8
Аугментации: что включено и почему
Ключевой принцип для рентгена: аугментации не должны разрушать анатомию.

Цветовые (безопасно)
yaml
hsv_h: 0.015    # оттенок — для ч/б снимков не имеет смысла, но и не вредит
hsv_s: 0.7      # насыщенность — имитирует разные аппараты
hsv_v: 0.4      # яркость — экспозиция
Эти преобразования имитируют различия в условиях съёмки рентгеновских аппаратов.

Геометрические
yaml
degrees:   10.0   # поворот — пациент мог лежать под углом
translate: 0.1    # сдвиг — центр кадра не всегда совпадает с анатомическим центром
scale:     0.5    # масштаб — разные размеры пациентов
shear:     0.0    # сдвиг — выключено, искажает анатомию
Отражения
yaml
fliplr: 0.5   # горизонтальное — безопасно
flipud: 0.0   # вертикальное — ВЫКЛЮЧЕНО: лёгкие оказываются снизу, это анатомически невозможно
Вертикальное отражение — классическая ошибка при обучении на медицинских данных. Для рентгена грудной клетки оно бессмысленно и вредно.

Mosaic — выключено
yaml
mosaic: 0.0
close_mosaic: 10   # не имеет эффекта при mosaic=0.0, оставлено для гибкости
Mosaic склеивает 4 случайных изображения в одно. Это стандартная аугментация YOLOv8 и хорошо работает на естественных изображениях (COCO, ImageNet), где объекты независимы от контекста.

Для рентгена это разрушает глобальную анатомическую структуру. Лёгкие, диафрагма, сердце всегда находятся в фиксированных местах. Mosaic создаёт сцены, которых не бывает в реальности — модель учится на артефактах. На реальном медицинском проекте мозаика была принудительно отключена именно по этой причине.

Что происходит при обучении
YOLO на каждой эпохе:

Прогоняет все train-изображения с аугментациями;

Считает 3 функции потерь: box_loss (координаты), cls_loss (классификация), dfl_loss (Distribution Focal Loss — точность боксов);

Прогоняет валидацию и считает precision, recall, mAP@0.5, mAP@0.5:0.95;

Сохраняет last.pt и (если метрика улучшилась) best.pt;

Пишет строку в results.csv.

Что сохраняется
text
runs/train/<run_name>/
├── weights/
│   ├── best.pt              # лучшая модель по mAP
│   ├── last.pt              # последняя модель (для resume)
│   └── epoch5.pt, ...       # каждые 5 эпох (при save_period=5)
├── results.csv              # таблица метрик по эпохам
├── results.png              # графики потерь и метрик
├── confusion_matrix.png     # матрица ошибок на валидации
├── PR_curve.png, F1_curve.png
├── train_batch0.jpg, ...    # примеры обучающих батчей
├── val_batch0_pred.jpg, ... # предсказания на валидации
├── labels.jpg               # распределение разметки
└── args.yaml                # все параметры, с которыми запускалось
