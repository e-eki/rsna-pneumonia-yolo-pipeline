## Заметки по экспериментам

### №1 — Smoke test

**Цель:** убедиться, что пайплайн работает end-to-end, прежде чем запускать полное обучение.

**Результат:** метрики растут монотонно (mAP@0.5: 0.08 → 0.24 → 0.27), функции потерь снижаются. Пайплайн валиден.

**Время:** ~20 минут


### №2 — Финальное обучение

**Цель:** получить рабочую модель для портфолио.
**Что изменилось относительно smoke test:**
- модель `yolov8n` → `yolov8s` (больше параметров);
- эпох 3 → 30;
- JPEG-конвертация датасета (3× ускорение I/O);
- mosaic отключена (`mosaic: 0.0`) - тк разрушает анатомическую структуру рентгена

**Результат:**
- Функции потерь падают монотонно, признаков переобучения нет (train/val разрыв ~8–10%).
- Метрики выходят на плато к 25-й эпохе.
- Precision и recall сбалансированы (0.40 / 0.38).
- `AR@0.50 = 0.92` — модель видит 92% очагов при IoU=0.5.

**Время:** ~3.9 часа
